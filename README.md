# 3005A3

This application uses JDBC with Java. It can be downloaded from https://jdbc.postgresql.org/download/. Make sure to add the downloaded file as a library before running the code. 

Make sure a table is created in a PostgreSQL database before beginning. The given SQL file has the code to create the table and fill in the initial info. 

The application is run from the file PostgreSQLJDBCConnection.java. Fill in the database credentials with the appropriate information (port number (after localhost:), DB name (after port number), user, and password).  

In the "Function calls" section, other than the getAllStudents() function, you can manipulate the given arguments to test the application to your own liking. For example, adding different students, changing their emails, and deleting students. 

Each function called will perform the associated SQL query in the database. Changes to the table will be shown in PostgreSQL. 

Run the file to view record information / manipulate records in the database! :)
